# Release 0.5.27 validation

Prepared on 31 October 2026, Asia/Manila. This patch adds clearer sidebar scrolling, direct saving while editing an existing scholar, separate profile remarks in Google reporting, and administrator-reviewed sheet pull for new profiles and updates. Schema 18 adds only durable import receipts; the migration does not rewrite prior business records.

## Observed software and interface checks

- Passed across completed runs: all 682 current backend cases. The full run passed 681 and found one stale schema-table assertion, which omitted the new receipt table. The assertion was corrected and all nine affected isolation tests passed on rerun; this is not presented as a single clean 682-test run. Combined statement/branch coverage is 91.86%, above the 87% gate (93.28% statements and 87.11% branches). Runtime/test Ruff checks and formatting passed for 104 files.
- Passed: all 293 frontend tests in 49 suites. Measured coverage is 83.23% statements, 76.24% branches, 78.85% functions and 86.62% lines. A final small callback refreshes record counts after an import; all 30 affected tests then passed, including a 12-to-13 scholar count integration check. The full coverage measurement precedes this callback and was not repeated afterward. Formatting and production/test types pass. The final callback's production build passed (Vite: 4.67 seconds), along with the final formatting check.
- Passed: production browser review using fictional records and an offline Google fixture. An existing scholar saved directly from Identity. A reviewed pull created one scholar, updated one scholar and created one independent grant; no existing grant was updated in that browser batch. The new profile was visible afterward. Current/source comparisons and confirmation were checked. A 698-pixel preview used its 701-pixel parent; page client/scroll widths were equal at 878 pixels on desktop and 445 pixels in the narrow browser view. No page-wide horizontal overflow was observed. After reloading the final production build, a second fictional import created one scholar and one grant: the same page immediately refreshed its count from 13 to 14 without reloading, and the browser console had no errors. These are browser viewport checks, not a physical mobile-device test.
- Passed: the disposable in-memory schema inventory is version 18, with 16 application/infrastructure tables and 126 columns. Current documentation identities, links, migration ceiling and export-header checks pass. The dependency inventory was refreshed after version metadata formatting.
