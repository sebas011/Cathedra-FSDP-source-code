## Preservation and limits

Existing nullable application groups retain their previous annual grouping. Existing histories are never automatically split based on inferred dates. Hard-copy and soft-copy states default to Not recorded and do not infer missing requirements. Degree/Certification/Enhancement are program categories separate from funding type. CSV headers remain unchanged; new optional facts are available in JSON/profile views and full database backups.

The release retains Summer, optional dates, uppercase record text and essential Name/Program Applied validation. Confirmed log saves close the editor; uncertain responses retain the original retry payload. Disclosure expansion/restoration for printing is covered by interaction tests.

No new whole-interface visual certification, remote CI result, GitHub 0.5.20 publication, actual Office-PC update or E-drive transfer is claimed. Never point an older runtime at a newly migrated schema without reviewed recovery. Local Office package publication is recorded separately from installation and synthetic acceptance.
